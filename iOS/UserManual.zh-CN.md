# 锦囊 用户手册

- 适用版本：锦囊 1.0.0
- 适用系统：iOS 15.0 及以上
- 文档语言：简体中文（English version: `UserManual.en.md`）

---

## 一、锦囊是什么

锦囊是一款「本地优先」的结构化信息与常用文本管理工具，配套一个自定义系统键盘。你可以把常用的**信息**、**网址**、**话术**分门别类地收纳起来，随后在任意 App 的输入框中，通过锦囊键盘一键输入，免去反复复制粘贴。

- 设计理念：构于微，行于简；收罗万绪，点触成文。
- 全部数据仅保存在你的设备本地，不上传服务器。

---

## 二、核心概念

### 1. 类别（Category）

锦囊按三种类别组织内容：

| 类别 | 用途 | 示例 |
| --- | --- | --- |
| 信息 | 结构化的字段信息 | 收件人、地址、邮编、电话、邮箱 |
| 网址 | 常用网址链接 | 官网、后台、文档地址 |
| 话术 | 含占位符的模板文本 | 客服回复模板、常用问候语 |

你可以在「设置 → 类别管理」中新增、重命名、删除、排序类别。

### 2. 词条（Entry）

每个类别下包含若干**词条**。一个词条是一组内容（例如一整套地址信息、一条网址、一段话术），拥有一个名称，便于查找与输入。

### 3. 分隔符（Separator）

录入「信息」类词条时，锦囊会按你选择的**分隔符**（如换行、逗号、竖线等）把一段文本自动拆分成多个字段。常用分隔符可在「设置 → 分隔符管理」中维护。

### 4. 替换值（Replacement Value）

「话术」类词条可包含占位符（形如 `%SCRIP1%`、`%SCRIP2%`）。在键盘中选择话术前，你可以先为占位符挑选**替换值**，输出时自动替换为对应内容。替换值在「设置 → 替换值管理」中维护。

## 三、快速上手

### 1. 新增内容

1. 在首页点击底部中间的「新增」。
2. 选择类别（信息 / 网址 / 话术）。
3. 按类别录入内容：
   - **信息**：粘贴或输入一段文本，选择合适的分隔符自动拆分为多个字段。
   - **网址**：输入网址；如开启「网址自动处理」，会在后台补全标题、元数据与网页快照。
   - **话术**：输入模板文本，可插入占位符供后续替换。
4. 填写名称并保存。

### 2. 查找与管理

- **搜索**：首页顶部中间的搜索框，支持对词条名称与内容的全文检索。
- **筛选 / 排序**：首页底部左右两侧分别提供筛选与排序。
- **编辑 / 删除**：在列表中左滑词条可进入编辑或删除。

## 四、启用并使用锦囊键盘

出于 iOS 的安全限制，App 无法自动开启键盘，需要你在系统设置中手动启用一次。

### 1. 启用键盘

1. 打开「使用说明」页，点击「打开系统设置」。
2. 依次进入「键盘 → 键盘 → 添加新键盘…」。
3. 在列表中选择「锦囊」，完成添加。
4. 如需读取剪贴板等功能，点开「锦囊」并打开「允许完全访问」。

### 2. 拉起并输入

1. 在任意可输入的位置点击输入框，调出键盘。
2. 长按左下角地球图标 🌐，或反复点击，切换到「锦囊」键盘。
3. 顶部横向切换类别，点击词条即可将内容输入到光标处。
4. 话术含占位符时，先在词条上方选择替换值，再点击输出。

### 3. 键盘常用操作

- **点击输入**：点击任意词条内容，立即输入到目标位置。
- **撤销 / 重做**：撤销或恢复最近一次的点击输入。
- **退格**：轻点删除一个字符；长按可持续退格，与系统键盘一致。
- **字号缩放**：通过「+ / −」调整键盘内文字的整体大小（跨会话记忆）。
- **打开锦囊 / 管理替换值**：键盘内提供入口，可快速跳回主 App 进行管理。

## 五、安全与解锁

锦囊使用设备的生物识别（Face ID / Touch ID）保护你的数据：

- 当设备支持生物识别且已有数据时，App 界面会在进入后台、锁屏或冷启动后要求验证。
- 键盘首次在**第三方 App**中展示数据前，需要你在主 App 通过生物识别授权；授权采用一次性票据机制，切换到其它 App 或重开后需重新授权。
- 当键盘是在**锦囊 App 内部**被唤起时（App 处于前台且已解锁），无需重复验证。
- 「设置 → 安全」提供「使用 Face ID 解锁并同步」与「立即锁定」。

> 生物识别仅在本机进行，锦囊不会存储或上传你的生物特征信息。

## 六、网址处理

- 在「设置 → 网址」中可开启「网址自动处理」。
- 开启后，新增网址时锦囊会在后台**访问你所填写的网址**，抓取网页标题、元数据并生成快照，便于识别与浏览。
- 处理进度可在主菜单「网址任务」中查看。

> 该功能是锦囊唯一会主动联网的场景，且仅访问你自己录入的网址，不涉及任何追踪或第三方统计。

---

## 七、数据统计

主菜单「数据统计」展示与隐私无关的使用行为计数，帮助你了解自己的使用情况：

- APP 打开次数
- 新增数据条数（一次新增算一条）
- 删除数据条数
- 键盘输入次数（在键盘点击一个输入项、写入目标位置算一次）
- 键盘输入字符数
- 统计起始与最近更新时间

> 统计不含位置、设备标识、输入内容等任何隐私信息，仅记录使用次数。

## 九、数据与隐私

- 全部业务数据仅保存在设备本地（SQLite 数据库）。
- 主 App 与键盘之间通过 App Group 共享**只读**数据快照；键盘不记录你的输入内容。
- 锦囊不集成任何第三方统计、广告或追踪 SDK，不采集位置信息。
- 详见《隐私政策》（`PrivacyPolicy.zh-CN.md`）与《用户协议》（`UserAgreement.zh-CN.md`）。

## 十、常见问题

**Q：切换不到锦囊键盘？**
请确认已在「系统设置 → 键盘」中添加「锦囊」，并在需要读取剪贴板时打开「允许完全访问」。

**Q：键盘里看不到内容，提示需要解锁？**
请回到锦囊主 App 完成一次 Face ID 授权后再使用；在锦囊 App 内部唤起键盘则无需重复验证。

**Q：网址标题一直没出现？**
请确认已开启「网址自动处理」并保持联网；可在「网址任务」中查看处理进度。

**Q：数据会同步到云端吗？**
不会。锦囊为本地优先应用，数据仅存于本机。
